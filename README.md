# Исла Мона — карта острова

Откройте **Isla_Mona.png** — готовая карта 2600 × 2100. **Isla_Mona.svg** — автономный редактируемый исходник: подписи, символы и дороги векторные, береговой рельеф встроен как PNG. **preview.jpg** — уменьшенная копия.

Игровые файлы и сохранения не изменены. Отдельная карта, не установка предмета в игру.

## Художественная карта и веб-страница

`Isla_Mona_art.png` — отдельная художественная карта 2400 × 2700. `art_preview.jpg` — уменьшенная копия. Исходная техническая PNG/SVG сохранена без изменений. Художественный вариант нарисован программно: собственные значки, горы, деревья, фактура бумаги и штриховка; пиксели карт-образцов не использованы. Берег построен по той же геометрии; пляжи, растительность и горные знаки декоративны и не являются точной съёмкой. Игровая подпись хозяйственного объекта — «Фактория», не «Плантация».

`index.html` — автономная страница без сборки, библиотек и внешних запросов. Два варианта карты, масштабирование, прокрутка и скачивание. Можно открыть локально двойным щелчком. `preview.html` перенаправляет на неё.

### Публикация на GitHub Pages

1. Запустите `skpy IslaMonoMap/tools/package_site.py` из папки игры (готовый архив также приложен).
2. Распакуйте **Isla_Mona_Pages.zip** в корень отдельного репозитория GitHub или загрузите содержимое папки **pages**. Не загружайте папку игры и не переносите архив как единственный файл: `index.html` должен лежать прямо в корне репозитория.
3. В репозитории откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, вашу ветку и **/(root)**, затем **Save**.
4. После завершения публикации ссылка появится в этом же разделе. Обычно адрес: `https://<имя>.github.io/<репозиторий>/`.

В комплект входят только HTML/CSS/JS, две PNG, технический SVG и `.nojekyll`. Модели игры, извлечённые геометрические данные и карты-референсы не включены. Публикация здесь не выполнялась. Изображение берега производно от ресурсов игры; публичная доступность ресурсов не означает передачу авторских прав. Карта неофициальная; перед распространением проверьте условия правообладателя. Лицензия на ресурсы игры этим проектом не предоставляется.

Пересобрать художественный вариант: `skpy IslaMonoMap/tools/render_art.py`. Затем повторить упаковку. Пересборка изображений требует Pillow и шрифта Georgia из Windows; готовая страница ничего этого не требует.

## Что достоверно

- Берег и рельеф взяты из `Resource/Models/Islands/IslaMona/IslaMona.gm`: 7897 треугольников, буфер 4523 вершин, отсечение у уровня моря y=0.05. Проекция сверху, одинаковый масштаб X и Z, +Z вверху. Декоративная роза ориентирована по этой системе модели; соответствие компасу запущенной игры отдельно не проверялось.
- Морские точки — `reload_1`, `reload_2`, `reload_3` из `Resource/Models/Islands/IslaMona/IslaMona_locators.gm`. Это точки подхода/высадки, не вычисленные центры пляжей.
- Названия — `Resource/INI/texts/russian/LocLables.txt:121–125,355–357`: «Исла Мона», «Форт в джунглях», «бухта Губернатора», «мыс Утопленника», «бухта Вьекес». Искомый пользователем остров «Исла-Моно» имеет внутренний ID `IslaMona`.
- Координаты 18°42′ с. ш., 72°09′ з. д. — буквально из квестового журнала, `Resource/INI/texts/russian/QuestBook/QuestBook_Part2.txt:3685`. Они не подменены вычислением из положения на глобальной карте.
- Связи дорог — `Program/locations/init/IslaMona.c:531–609,654–665,728–739,820–831`. Пещерный маршрут — строки 43–48,87–99,136–153,322–338,438–448.

## Ограничения точности

Наземные локации — отдельные игровые сцены, общей непрерывной географической системы у них нет. Поэтому положение посёлка, фактории, пещеры, развилок и изгибы дорог на общем силуэте **условны**. Топология переходов сохранена. По линиям нельзя измерять расстояния или судить о сторонах поворота; для поворотов предназначена правая панель.

Повороты восстановлены из взаимного расположения выходов моделей Jungle3, Jungle5, Jungle13L. От бухты Губернатора к посёлку — налево. От Вьекес — налево к первой развилке, затем направо. После развития базы первая лесная сцена заменяется: `Program/quests/Sharlie/IslaMona.c:217–236`, используется `jungle13L_locators`, а не `jungle13_locators` (у них переставлены выходы 2 и 3). Направление к посёлку сохраняется. Это геометрическая интерпретация, **прохождение с управлением персонажем в игре не проверено**.

Мыс Утопленника ведёт к пещере и через подвал/дом к посёлку, а не к лесной развилке. Боковая затопленная пещера в навигационную карту не включена. Доступность мыса, фактории и отдельных переходов зависит от квестового этапа. Морской мыс изначально закрыт (`Program/islands/islands_init.c:2665–2672`), открывается квестом; фактория доступна после постройки (`Program/quests/Sharlie/IslaMona.c:673–676`). Поздние стадии меняют вход в подвал (`:112–127`). Карта содержит сведения о скрытых местах.

## Воспроизведение

Запускать из корня игры:

```
skpy IslaMonoMap/tools/extract_geometry.py
skpy IslaMonoMap/tools/render_map.py
skpy IslaMonoMap/tools/verify_map.py
```

`data.json` содержит подписи, координаты и граф, `research/geometry.json` — извлечённую поверхность. Изображения Доминики/Барбадоса в `research` извлечены из игровых текстур как референсы. Примеры из C:\Downloads\_process открыть было запрещено границей рабочей папки; доступ не обходился.

Описание формата GM сверено с `rdf.h` Storm Engine, commit `a68f43df197a50c5177f40209abc109f01f4b114`:
https://github.com/storm-devs/storm-engine/blob/a68f43df197a50c5177f40209abc109f01f4b114/src/libs/geometry/src/rdf.h

Существующий `_mod_tools/gm_locators.py` неточно называет поля/выравнивание, но выводимые позиции совпадают с матрицами. Он не менялся; проверка карты читает локаторы независимо по структуре RDF_LABEL.
